# 《万剑归宗》AI 美术资产提示词全集（弹壳特攻队质感版）

> 目标风格：参考《弹壳特攻队》第一章「城市大街」的表现标准 ——
> Q版二头身角色 + 软阴影、俯视纹理地面 + 建筑斜投影 + 暗角聚光、亮芯弹道拖尾、
> 持久血渍贴花、圆形技能图标徽章、深色底高饱和点缀。
> 生成后按【文件名】存入 `wanjiang/assets/`，刷新游戏自动替换程序化造型（缺哪张用哪张的默认）。

---

## 0. 使用说明

**推荐工具**：即梦AI / 可图 / 通义万相 / 腾讯混元（中文直出，支持垫图保风格）；
Midjourney（用英文版提示词，加 `--style raw`，同一 `--seed` 保风格一致）；
像素风备选：Retro Diffusion / Aseprite。

**两种背景管线（重要）**：
- **角色/怪物/道具** → 用「纯洋红色背景 #FF00FF」生成 → 抠图（remove.bg / PS魔棒 / python rembg 批量）→ 存透明 PNG；
- **光效类（弹道/灵气珠/剑气/龙卷）** → 用「纯黑背景」生成 → 不用抠图，游戏代码里以发光叠加(lighter)绘制，黑底直接消失。

**风格一致性技巧**：
1. 所有提示词共用第 1 节的「风格基座」，不要改写；
2. 同一工具固定 seed（MJ: `--seed 1234`；即梦/可图：上传第一张满意的图作参考图垫图）；
3. 一次生成 4 张挑 1 张，角色全家福最好同一批出。

**尺寸规格**（生成大图，引擎自动缩放）：

| 文件名 | 建议生成尺寸 | 游戏内显示 |
|---|---|---|
| player.png | 512×512 | ~54px |
| sword_tier0~5.png ×6 | 256×256 | ~30px |
| bullet_enemy.png / orb_spirit.png | 128×128 | 22 / 16px |
| monster_wolf / bat / ghost.png | 256×256 | 38~46px |
| monster_elite.png | 512×512 | 75px |
| boss_heishan.png / _rage.png | 768×768 | ~115px |
| pickup_*.png ×5 | 128×128 | 40px |
| fx_*.png（特效） | 512~1024 | 叠加层 |
| bg_ch1_sky / far / near.png | 720×1280 | 三视差层 |

**视角约定**：角色与怪物贴图统一**俯视/微俯 3/4 视角，怪物面朝屏幕下方**（正朝玩家扑来）；
飞剑贴图**剑尖朝上**；Boss/蝠妖/符鬼/剑仙为正面构图，代码不旋转。

## 8. 生成后的处理清单

1. 洋红底图 → 抠图成透明 PNG（remove.bg / PS / `pip install rembg` 批量：`rembg p in/ out/`）；
2. 黑底光效图 → 不处理，直接存 PNG（代码 additive 绘制）；
3. 按【文件名】命名，放入 `wanjiang/assets/`；
4. 刷新游戏（`http://localhost:8642/`），缺失的自动用程序化造型，生成的自动替换；
5. 地图三层：far/near 上下边缘加 64px 透明渐变 → 无缝滚动。
```
