> 配套：风格基座与现有怪物原画提示词见 `docs/美术提示词.md`；工程结构见 `AGENTS.md`。
> 现状：游戏内怪物已有**程序化动画兜底**（行走起伏/扑击拉伸/蓄力脉冲/震地预警圈/施法红光——零素材也活的）。

## 1. 动画设计总览

每只怪四类动作状态，优先级：死亡(代码粒子) > 攻击 > 移动 > 待机。

| 怪物 | 移动动画 | 攻击动画 | 攻击行为（已实装） | 序列帧规格 |
|---|---|---|---|---|
| 狼妖 | 4帧跑动（身体起伏+四腿交替） | 3帧扑咬（压低蓄力→扑出拉伸→收势） | 190px 内蓄力0.22s→2.6倍速扑击 | _walk 4帧 / _atk 3帧 |
| 蝠妖 | 4帧扇翅（翅上抬/展开/下压/收拢） | 俯冲姿势1帧（随机俯冲时切换） | 正弦追击 | _fly 4帧 |
| 符鬼 | 2帧漂浮起伏（纸面飘动） | 2帧施法（符眼亮红→符文喷射，出手前0.35s红光预警已实装） | 保持300px距离吐符弹 | _float 2帧 / _cast 2帧 |
| 妖将 | 4帧沉重行进（缓、顿挫） | 3帧震地（双拳高举→砸地→波纹，蓄力0.45s红圈预警已实装） | 170px 内蓄力→120px 范围震地18伤 | _walk 4帧 / _slam 3帧 |
| 黑山老妖 | 4帧呼吸待机（腹部起伏） | 咆哮2帧（张口喷焰，径向弹幕时切）+ 冲撞蓄力1帧（闪烁预警已实装） | 径向弹幕/螺旋弹/冲撞 | _idle 4帧 / _roar 2帧 |

**风格铁律**：同一只怪所有帧的轮廓、配色、大小、装饰完全一致，只变姿势；脚底基准线对齐；统一面朝右（代码按运动方向旋转）；交付透明底（生成阶段用绿幕/纯色幕布，抠图见 §2）；每帧之间无补间（引擎按 fps 播放）。

## 2. 生成管线（按推荐顺序）

### 管线 1（首推）：关键姿势参考图 → 视频化 → 绿幕抠图 → 降帧 → 对齐 → 引擎测试
完整七步（实测总结，工具链可替换、流程逻辑通用）：

1. **关键姿势参考图**：生图工具先出 2 张关键姿势（待机、奔跑/攻击），背景选**纯色幕布**——视频化用绿幕最稳（角色含黑服/白发时必用绿幕；若角色配色与绿不冲突，黑白灰底也可）；
2. **视频化**：把参考图导入 Seed 系视频工具（Seedance / 即梦 / 可灵），提示词要求生成**连贯动作片段**：一段视频包含 待机 → 待机转跑 → 奔跑（每个游戏状态一段，对应 §1 动作清单）；
3. **截取与抠图**：按动作分段截取（如待机段 48 帧）；先粗抠再精修边缘；若有绿边，降低绿色饱和度或直接涂黑；
4. **降帧与导出**：抽帧降载——每 4 帧保留 1 帧（48→12），再按奇/偶取半到 6 帧；导出**带透明背景的 PNG 序列**；
5. **对齐与拼接**：以画布为锚点把各动作段（待机/过渡/奔跑）载入可视化工具（Animation Tuner 类），以基准动画为参照逐段调偏移，确保状态切换不跳帧；
6. **导入与测试**：在引擎里建实验场景，载入 idle / idleToRun / run 实跑，反复调速度与对齐直到流畅；
7. **性能优化**：内存/包体吃紧 → 画布缩小一半≈占用降为 1/4，或继续减帧——低分辨率下观感差异不大。

**关键经验（踩坑总结）**：
- AI 直接生成精灵图集（一次画 N 帧网格）不可靠，不要用；
- AI 直出透明背景不稳定 → 一律绿幕/纯色幕布生成，抠图是必经环节；
- 视频生成必然带背景 → 后期处理不可省；
- 工具链可替换（Seedance/即梦/可灵、抠图工具任选），**流程逻辑通用**。

### 管线 2（备选）：垫图逐帧
即梦 / 可图 / ChatGPT图像：上传原画垫图 + §4 的逐帧提示词，一张一张生成单帧 → 对齐拼合。适合只要 2~4 帧的简单循环。

### 管线 3（零素材，已实装）：程序化动画增强
代码已内置，无需任何素材：行走起伏、扑击拉伸（蓄力脉冲→2.6倍速突进）、妖将震地红圈预警、符鬼施法红光、Boss 蓄力闪烁、受击闪白。**序列帧没生成时游戏动画也不死板**，生成后自动升级替换（§5）。

**对齐铁律**：所有帧画布同尺寸；角色脚底贴同一水平基准线；角色中心水平对齐；面朝右；透明底。攻击第一帧必须与移动循环第一帧姿势衔接。
**过渡段**：管线的"待机转跑"片段单独截出（如 `idle_to_run` 3 帧），插在状态切换处消除跳帧；每段动作首帧姿势 = 上一段末帧姿势。
**降帧**：视频 30~48fps 先抽到 8~12fps，再按奇偶取半——移动循环 6~8 帧、攻击 3 帧已够顺滑。

## 5. 代码接入规格（AI 实现用）

1. `ASSET_LIST` 追加上表文件名（每段动作一张雪碧图：`_idle` / `_run` / `_atk` / `_slam`…）；
2. 轻量帧动画播放器：`frame = Math.floor(clipT * fps) % N`，从雪碧图取 `srcX = frame * 帧宽`；锚点=底部中心（脚贴地），按运动方向水平翻转（`ctx.scale(-1,1)`）；
3. **状态剪辑映射**（对应管线 1 的分段）：`待机→_idle`、`追击→_run`、`windup/攻击→_atk`（播一遍后回 _run）、`待机转跑→_idle_to_run`（插在静止→移动切换处，播完接 _run）；
4. 触发钩子已就位：`windup>0` / `slamT>0` / `lungeT>0` 即攻击剪辑播放窗口；
5. 性能：雪碧图画布减半 ≈ 显存/内存 1/4；移动循环 6~8 帧、攻击 3 帧足够；
6. 实装后管线 3 的程序化动画自动降级为兜底（帧缺失时仍走现有 draw 路径，无需删代码）。
