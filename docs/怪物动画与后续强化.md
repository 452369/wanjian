# 怪物动画与后续强化 · 资产生成全流程

> 配套：风格基座与现有怪物原画提示词见 `docs/美术提示词.md`；工程结构见 `AGENTS.md`。
> 现状：游戏内怪物已有**程序化动画兜底**（行走起伏/扑击拉伸/蓄力脉冲/震地预警圈/施法红光——零素材也活的）。

## 1. 动画设计总览

每只怪四类动作状态，优先级：死亡(代码粒子) > 攻击 > 移动 > 待机。

| 怪物 | 移动动画 | 攻击动画 | 攻击行为（已实装） | 序列帧规格 |
|---|---|---|---|---|
| 狼妖 | 4帧跑动（身体起伏+四腿交替） | 3帧扑咬（压低蓄力→扑出拉伸→收势） | 190px 内蓄力0.22s→2.6倍速扑击 | _walk 4帧 / _atk 3帧 |
| 蝠妖 | 4帧扇翅（翅上抬/展开/下压/收拢） | 俯冲姿势1帧（随机俯冲时切换） | 正弦追击 | _fly 4帧 |
| 符鬼 | 2帧漂浮起伏（纸面飘动） | 2帧施法（符眼亮红→符文喷射，出手前0.35s红光预警已实装） | 保持300px距离吐符弹 | _float 2帧 / _cast 2帧 |
| 妖将 | 4帧沉重行进（缓、顿挫） | 3帧震地（双拳高举→砸地→波纹，蓄力0.45s红圈预警已实装） | 170px 内蓄力→120px 范围震地18伤 | _walk 4帧 / _slam 3帧 |
| 黑山老妖 | 4帧呼吸待机（腹部起伏） | 咆哮2帧（张口喷焰，径向弹幕时切）+ 冲撞蓄力1帧（闪烁预警已实装） | 径向弹幕/螺旋弹/冲撞 | _idle 4帧 / _roar 2帧 |

**风格铁律**：同一只怪所有帧的轮廓、配色、大小、装饰完全一致，只变姿势；脚底基准线对齐；统一面朝右（代码按运动方向旋转）；透明底；每帧之间无补间（引擎按 fps 播放）。

## 2. 三条生成管线（按推荐顺序）

### 管线 B（首推）：原画 → 图生视频 → 抽帧
动作最自然、风格 100% 一致。工具：可灵 / 即梦AI视频 / Vidu。

1. 用已抠好的原画（如 `assets/src/monster_wolf.png`）作首帧/垫图；
2. 输入动作提示词（模板见 §4 末尾）生成 2~4 秒循环视频，如：
   > 这只深紫色妖狼原地奔跑，四肢交替、身体轻微起伏，循环动画，镜头固定不动，纯黑背景，无镜头运动，无其他物体
3. 抽帧（本项目 `serve.js` 已支持 Range，也可浏览器里抽）：
   ```bash
   ffmpeg -i wolf_walk.mp4 -vf fps=8,scale=256:256 frames/w_%02d.png
   ```
4. 从抽帧里挑姿势差异最大的 4 帧，按顺序拼成横排雪碧图（PS/在线拼图均可），导出 `monster_wolf_walk.png`（1024×256）。

### 管线 A：垫图逐帧
即梦 / 可图 / ChatGPT图像：上传原画垫图 + §4 的逐帧提示词，一张一张生成单帧 → 对齐拼合。姿势一致性靠"同一只+完全一致"措辞与垫图保证。

### 管线 C（零素材，已实装）：程序化动画增强
代码已内置，无需任何素材：行走起伏、扑击拉伸（蓄力脉冲→2.6倍速突进）、妖将震地红圈预警、符鬼施法红光、Boss 蓄力闪烁、受击闪白。**序列帧没生成时游戏动画也不死板**，生成后自动升级替换（§5）。

## 5. 代码接入规格（AI 实现用）

1. `ASSET_LIST` 追加上表文件名；
2. 实现轻量帧动画播放：绘制时 `frame = Math.floor(monster.t * fps) % N`，从雪碧图取 `srcX = frame * 帧宽`；
3. 锚点=底部中心（脚贴地），按运动方向水平翻转（`ctx.scale(-1,1)`）；
4. 触发时机与现有状态机对齐：移动状态播 _walk/_fly；`windup>0` 或 `slamT>0` 或 `lungeT>0` 时播 _atk/_slam 一次后回循环；
5. 实装后 §2.C 程序化动画自动降级为兜底（帧缺失时仍走现有 draw 路径，无需删代码）。
